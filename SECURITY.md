# Security policy

## Supported versions

Security fixes are released for the latest version of `thingsboard_client`.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Email them to [security@thingsboard.io](mailto:security@thingsboard.io).

Describe the problem, the affected versions and how to reproduce it. We will reply by email.

Vulnerabilities of the ThingsBoard server itself belong to the [ThingsBoard repository](https://github.com/thingsboard/thingsboard).
