# Security policy

## Supported versions

Security fixes are released for the latest version of `thingsboard_client`.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Report them privately through GitHub: open the [Security tab](https://github.com/thingsboard/dart_thingsboard_client/security) of this repository and choose **Report a vulnerability**.

Describe the problem, the affected versions and how to reproduce it. We will reply in the advisory.

Vulnerabilities of the ThingsBoard server itself belong to the [ThingsBoard repository](https://github.com/thingsboard/thingsboard).
